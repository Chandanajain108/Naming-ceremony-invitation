NAMING CEREMONY INVITATION - BEGINNER SETUP

1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Install the VS Code extension "Live Server" by Ritwick Dey.
4. Open index.html.
5. Right-click index.html -> Open with Live Server.
6. The invitation opens in your browser.

PHOTOS
Replace these files inside assets/ (keep exactly the same names):
- photo1.jpg = main baby photo
- photo2.jpg = venue photo
- photo3.jpg = video/celebration photo
- photo4.jpg = gallery photo

TEXT / DATE
Open index.html and change Nair, event date, Hall Complex and address.
Then open script.js and change EVENT_DATE to your real event date/time.

MUSIC
Put your MP3 file inside assets and name it music.mp3.
Browsers normally block autoplay. The visitor must tap the music button first.

MAP
In index.html search for "google.com/maps?q=Koramangala" and replace the place with your venue.

GALLERY
The Upload button lets you preview additional photos locally in the browser. For permanent photos, replace the JPG files in assets.

WHAT IS USED
HTML5 = page structure
CSS3 = exact-style colors, scalloped shapes, flowers, responsive layout and animations
JavaScript = countdown, carousels, scroll reveal, gallery upload/lightbox, music and form interaction
No framework is required.
